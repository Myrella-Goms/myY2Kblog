tailwind v4

quando importamos o tailwind, ele define essas camadas:

@layer theme, base, components, utilities;

@import "./theme.css" layer(theme);
@import "./preflight.css" layer(base);
@import "./utilities.css" layer(utilities);

a camada de theme serve para definir os tokens que serão usados no nosso projeto, nas classes utilitárias (a depender do nome do token, ele pode ser usado por baixo dos panos pelo tailwind, no preflight)

a camada base aplica regras globais no projeto, essa camada usa o preflight que já possui regras definidas para padronizar comprotamos entre navegadores diferentes. 

    *preflight é um conjunto de estilos base projetados para suavizar inconsitências entre diferentes navegadores, como se fosse um reset.css/normalize.css.

ANIMAÇÕES COM CSS:  

mudanças de regras de um elemento ao longo do tempo.

entendo que criamos uma classe de estilização com as propriedades de animação que eu quero e no keyframe estabelecemos as regras

precisamos fazer um bind entre o nome da animação com o keyframe (identificador de uma aplicação que deve ser referenciado)

- algumas propriedades: 
animation-name: mesmo nome do keyframe para referenciar

animation-duration: tempo que a transformação entre o estado inicial e o que eu quero deve ocorrer

animation-timing-function: define a curva de velocidade que a animação deve ocorrer; ex: linear, ease-in;

animation-interation-count: quantas vezes essa animação deve ser aplicada ao elemento

animation-fill-mode: qual estado manter no elemento após executar a animação. ex: forwards, backwards

animation-delay: a partit de quanto tempo a animação deve ser executada

3 estados de uma animação, posso colocar mais estados, posso colocar de to from com transform

ex:
songs = [ {value: 'A'}, {value: 'B'}, {value: 'C'} ]
newValue = 'B'
Iteração 0: song = {value:'A'} → 'A' === 'B' → false
Iteração 1: song = {value:'B'} → 'B' === 'B' → true → findIndex retorna 1

renderização condicional = caso tenha opções, exiba o song.value, song.label

O <select> é controlado pelo prop value que você passa (songs[currentIndex].value).

Quando currentIndex muda (por clique nos botões ou por setCurrentIndex), o componente pai re-renderiza e passa um novo value para o Select. O navegador então marca a <option> cujo value casa com esse value e mostra o texto (option.label) dessa opção automaticamente — você não precisa "informar" o label ao select, o browser usa a <option> correspondente.

ao selecionar uma option, o evento de change captura o valor do target, dispara e envia o valor que o usuario escolheu
